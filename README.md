<h1><b>Melee Summit 11: The 1 Frame That Changed Melee</b></h1>

A webpage exploring Smash Summit 11. Highlighting the iconic one-frame moment that became a defining moment at Melee Summit 11 between Mang0 and Zain, in competitive Super Smash Bros. Melee.

<h1><b>Why I made this?</b></h1>

Well, I made this website because Super Smash Bros. Melee. is a game I find interesting and love. Not just because of the fast and technical gameplay. But also because of its history and rich stories, and I wanted to highlight my favorite one. That being Mang0 vs Zain at Melee Summit 11.

<h1><b>How to run it?</b></h1>

To view this website, simply click the link in the repository to enter the website directly from your browser. If you would like to run it locally, you can clone this repository and run via VS code live server. 

<h1><b>How was it made?</b></h1>

It was made with HTML and CSS, plus images taken from google. HTML and CSS were used for structure and styling, while the images were use mainly as visual aid and for visitors to see what thee players looked like.

<h1><b>Some Challenges</b></h1>

The main challenge I faced while making this website was formatting the images. The source images came from google, meaning there sizes and ratio are very different. Because of this I had to resize the images myself. Furthermore, putting the images in a side by side layout was quite challenging also. Mainly because I did not know how to stop the images from overlapping, but I eventually figured it out.
